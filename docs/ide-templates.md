# PhpStorm / IntelliJ IDEA

Project File Templates include `declare(strict_types=1)` and author:

```text
@author rooneyi <22ki129@esisalama.org>
```

Templates are stored in:

```text
.idea/fileTemplates/
```

After cloning, open the project in PhpStorm. If templates do not appear immediately:

1. Settings → Editor → File and Code Templates
2. Confirm PHP Class / Interface / Enum / Trait include the project templates
3. Optionally set Settings → Editor → File and Code Templates → Includes → PHP File Header
